## Abstract

Structured illumination microscopy (SIM) surpasses the optical diffraction limit and offers a two-fold enhancement in resolution over diffraction limited microscopy. However, it requires both intense illumination and multiple acquisitions to produce a single high-resolution image. Using deep learning to augment SIM, we obtain a five-fold reduction in the number of raw images required for super-resolution SIM, and generate images under extreme low light conditions (at least 100× fewer photons). We validate the performance of deep neural networks on different cellular structures and achieve multi-color, live-cell super-resolution imaging with greatly reduced photobleaching.

## Smart microscopy principle

Classical 2D-SIM needs 9 raw frames per super-resolved plane (3 illumination phases × 3 pattern orientations); 3D-SIM demands 15. That raw-frame budget is what caps SIM's speed and compatibility with gentle live-cell imaging — every frame costs illumination dose. Jin et al. train U-Net-style CNNs (DL-SIM and a scanning variant SR-SIM) on pairs of (few-frame, low-dose) and (full-frame, high-dose) SIM acquisitions, and show that **3 raw frames suffice** to recover the full 9-frame SIM reconstruction at comparable resolution, with the same network tolerating 100× lower photon counts per frame.

The smart-microscopy contribution is an acquisition-plan change, not just a reconstruction trick: because the network supplies the missing phases/orientations from a learned prior, the microscope can **acquire fewer raw frames on purpose**. That translates directly into faster live super-resolution, less photobleaching across a timelapse, and SIM on samples too dim or fragile for full-frame acquisition. The acquisition budget sits on both sides of the pipeline — dose-per-frame and number-of-frames — and DL-SIM cashes in both.

Caveats follow CARE's lesson: the network is content-aware, so a model trained on mitochondria won't recover microtubule-class images. Paired training data per structure class is an upfront cost, and the learned phases are a prior — not a substitute — so anything the prior hasn't seen (novel structures, fine features at the edge of SIM's resolution) risks being hallucinated away or filled in incorrectly.

## Implementation on pymmcore-plus

SIM itself isn't a native pymmcore-plus acquisition mode — it needs an SLM or grating device to impose illumination patterns and a matched reconstruction step. The smart-microscopy layer on top, though, maps cleanly onto `MDASequence` + `run_events`: each super-resolved frame is a short sequence of raw frames at prescribed (phase, orientation) states, and DL-SIM simply shortens that sequence.

```python
from useq import MDASequence, MDAEvent
from src.core.hardware.core import run_events

# Full 2D-SIM: 3 phases × 3 orientations = 9 raw frames per super-resolved plane.
# DL-SIM: 3 raw frames (one per orientation, single phase) is enough.

PHASES = [0, 1, 2]        # SLM pattern phase index
ORIENTS = [0, 1, 2]       # SLM pattern orientation index

def full_sim_events(t_loops=20, interval=1.0):
    for t in range(t_loops):
        for ori in ORIENTS:
            for ph in PHASES:
                yield MDAEvent(
                    index={"t": t, "o": ori, "p": ph},
                    exposure=50,
                    min_start_time=t * interval,
                    properties=[
                        ("SLM", "Orientation", str(ori)),
                        ("SLM", "Phase", str(ph)),
                    ],
                    channels=[{"config": "GFP"}],
                )

def dl_sim_events(t_loops=20, interval=1.0):
    # Acquire 3 raw frames per super-resolved plane: one orientation each,
    # fixed phase. ~5x fewer frames + lower exposure per frame.
    for t in range(t_loops):
        for ori in ORIENTS:
            yield MDAEvent(
                index={"t": t, "o": ori},
                exposure=10,                 # dim illumination — network restores SNR
                min_start_time=t * interval,
                properties=[
                    ("SLM", "Orientation", str(ori)),
                    ("SLM", "Phase", "0"),
                ],
                channels=[{"config": "GFP"}],
            )

# Reconstruct each 3-frame bundle with the trained DL-SIM model after acquisition.
from dl_sim_model import DLSIM   # external, trained offline on paired data
model = DLSIM.load("models/dl_sim_mitochondria.pt")

bundle, reconstructed = [], []
def on_frame(img, event, meta=None):
    bundle.append(img)
    if event.index["o"] == ORIENTS[-1]:
        sr = model.predict(bundle)           # 3 raw → 1 super-resolved frame
        reconstructed.append(sr)
        bundle.clear()

run_events(core, list(dl_sim_events()), on_frame=on_frame)
```

Modules to add to `src/core/`:

- An SIM-acquisition helper that generates (phase, orientation) event sequences for a given SLM/grating device — no such module exists yet; candidate for `src/core/hardware/sim.py`.
- A restoration wrapper alongside the CARE one (see [[Papers/Weigert 2018]]) — DL-SIM is architecturally very close, and both could share `src/core/analysis/restoration.py`.
- Calibration discipline: the "3 frames + low dose" budget is only safe for structure classes the model has been trained on. Validate on a held-out prep (compare against full 9-frame SIM reference) before a long live imaging run.

When DL-SIM is *not* the right tool: novel structures outside the training distribution, measurements where pixel intensities are quantitatively load-bearing (the restoration re-normalises), or any setup without access to paired full-dose/full-frame training data.
