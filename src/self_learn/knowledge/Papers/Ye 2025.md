## Abstract

Scanning microscopy systems, such as confocal and multiphoton microscopy, are powerful imaging tools for probing deep into biological tissue. However, scanning systems have an inherent trade-off between acquisition time, field of view, phototoxicity, and image quality, often resulting in noisy measurements when fast, large field of view, and/or gentle imaging is needed. Deep learning could be used to denoise noisy microscopy measurements, but these algorithms can be prone to hallucination, which can be disastrous for medical and scientific applications. We propose a method to simultaneously denoise and predict pixel-wise uncertainty for scanning microscopy systems, improving algorithm trustworthiness and providing statistical guarantees for deep learning predictions. Furthermore, we propose to leverage this learned, pixel-wise uncertainty to drive an adaptive acquisition technique that rescans only the most uncertain regions of a sample, saving time and reducing the total light dose to the sample. We demonstrate our method on experimental confocal and multiphoton microscopy systems, showing that our uncertainty maps can pinpoint hallucinations in the deep learned predictions. Finally, with our adaptive acquisition technique, we demonstrate up to 16X reduction in acquisition time and total light dose while successfully recovering fine features in the sample and reducing hallucinations. We are the first to demonstrate distribution-free uncertainty quantification for a denoising task with real experimental data and the first to propose adaptive acquisition based on reconstruction uncertainty.

## Smart microscopy principle

Uncertainty-driven adaptive acquisition closes the loop between a deep-learning reconstruction model and the scanner: a first pass collects a sparse/low-dose scan, the network produces both a denoised image and a calibrated pixel-wise uncertainty map (via conformal prediction for distribution-free guarantees), and the microscope then rescans only the pixels/tiles where uncertainty exceeds a threshold. The uncertainty signal doubles as a hallucination detector — regions where the network is most likely to invent features are precisely the ones flagged for rephotoning. This turns the photon budget into an information-matched resource: featureless background pays once, edges and fine structure pay proportionally to how much the model still doesn't know. The paradigm generalises beyond denoising to any reconstruction task whose uncertainty can be calibrated against held-out data.

## Implementation on pymmcore-plus

The control loop is a two-phase generator: Phase 1 performs a coarse (subsampled) scan, Phase 2 re-visits only the pixels/tiles that the uncertainty map marks as uncertain. In pymmcore-plus terms, subsampled scanning maps to a sparse grid of XY positions (or to an ROI list if the stage/galvo supports pixel-level sparsity); the rescan is a second `MDASequence` driven by the uncertainty mask.

```python
import numpy as np
from useq import MDAEvent, MDASequence
from src.core.hardware.core import run_events

# --- Phase 1: coarse / sparse scan over the full FOV ---
coarse_seq = MDASequence(
    stage_positions=[{"x": x, "y": y} for (x, y) in coarse_grid],
    channels=[{"config": "GFP", "exposure": 20}],   # low dose
)

tiles = {}  # (ix, iy) -> image

def collect_on_frame(img, event, meta=None):
    tiles[(event.index["p"],)] = img

run_events(core, list(coarse_seq), on_frame=collect_on_frame)

# --- Denoise + predict pixel-wise uncertainty on the stitched coarse scan ---
coarse = stitch(tiles, coarse_grid)
denoised, uncertainty = denoise_with_uncertainty(coarse)  # model outputs (y_hat, u)

# --- Phase 2: rescan only tiles whose uncertainty exceeds threshold ---
U_THRESH = conformal_threshold(calibration_set, alpha=0.10)  # 90% coverage

def uncertain_tiles(coarse_grid, uncertainty, tile_px):
    for (ix, iy), (x, y) in enumerate_grid(coarse_grid):
        patch = uncertainty_patch(uncertainty, ix, iy, tile_px)
        if patch.mean() > U_THRESH:
            yield (x, y)

refine_positions = list(uncertain_tiles(coarse_grid, uncertainty, tile_px=256))

refine_seq = MDASequence(
    stage_positions=[{"x": x, "y": y} for (x, y) in refine_positions],
    channels=[{"config": "GFP", "exposure": 200}],  # high dose only here
)
run_events(core, list(refine_seq))
```

Production hooks in `src/core/`:

- `../../../src/core/workflows/scanning.py` — `scan_and_detect` / `scan_events` provide the Phase-1 coarse-grid primitive.
- `../../../src/core/workflows/multiscale.py` — `multiscale_acquire` already implements hierarchical N-level acquisition; an uncertainty-mask selector would replace its current score function to drive the next level.
- An uncertainty-driven workflow module (`src/core/workflows/uncertainty_driven.py`) does not exist yet; this paper motivates one that takes a reconstruction model + calibration set and returns a rescan mask per frame. Key knobs: conformal-prediction α (coverage target), tile size for the rescan mask, and a `max_refine_fraction` budget cap so pathological frames don't blow the photon budget.

Calibration on a real prep: hold back a small set of sparse/dense-pair images from the same sample class, compute the residual distribution, and set the uncertainty threshold via conformal prediction to the desired coverage (typically α=0.10 for 90% pixel-level coverage). Re-calibrate when sample type or optics change — the guarantee is only valid under the same distribution.
