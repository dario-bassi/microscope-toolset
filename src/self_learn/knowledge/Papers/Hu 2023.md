## Abstract

The resolution and contrast of microscope imaging is often affected by aberrations introduced by imperfect optical systems and inhomogeneous refractive structures in specimens. Adaptive optics (AO) compensates these aberrations and restores diffraction limited performance. A wide range of AO solutions have been introduced, often tailored to a specific microscope type or application. Until now, a universal AO solution - one that can be readily transferred between microscope modalities - has not been deployed. We propose versatile and fast aberration correction using a physics-based machine learning assisted wavefront-sensorless AO control (MLAO) method. Unlike previous ML methods, we used a specially constructed neural network (NN) architecture, designed using physical understanding of the general microscope image formation, that was embedded in the control loop of different microscope systems. The approach means that not only is the resulting NN orders of magnitude simpler than previous NN methods, but the concept is translatable across microscope modalities. We demonstrated the method on a two-photon, a three-photon and a widefield three-dimensional (3D) structured illumination microscope. Results showed that the method outperformed commonly-used modal-based sensorless AO methods. We also showed that our ML-based method was robust in a range of challenging imaging conditions, such as 3D sample structures, specimen motion, low signal to noise ratio and activity-induced fluorescence fluctuations. Moreover, as the bespoke architecture encapsulated physical understanding of the imaging process, the internal NN configuration was no-longer a "black box", but provided physical insights on internal workings, which could influence future designs.

## Smart microscopy principle

Sensorless adaptive optics classically solves a Zernike-mode optimisation: for each of N modes, sweep M bias amplitudes, score each bias with an image-quality metric, fit a parabola, apply the peak. That's N·M snaps per correction and it has to be repeated whenever the sample moves. Hu et al. collapse the loop to a **single inference step**: a small CNN takes a few bias-imaged frames, computes a pseudo-PSF that is specimen-structure-independent, and predicts the Zernike coefficients directly. The physics embedding (the pseudo-PSF pre-processing) is what lets the network stay tiny and generalise across microscope modalities — the same architecture runs on two-photon, three-photon, and widefield 3D-SIM without retraining the core design.

The smart-microscopy contribution is to **put aberration correction on the same footing as single-shot autofocus**: an inference callback inside the acquisition loop, not a separate calibration phase. Because the NN is embedded in the control loop — not run post hoc — the microscope maintains its own wavefront against motion, SNR dips, and activity-induced fluctuations. This turns AO from a per-experiment setup cost into a per-frame correction cheap enough to run before every position of a multi-position timelapse or deep-tissue z-stack.

The transferable idea beyond deformable mirrors: any optimisation over a small parameter vector that currently uses a sweep-and-fit protocol (AO modes, correction-collar position, light-sheet alignment, SIM pattern phase) can be replaced with a physics-conditioned NN that regresses the correction from one or a few bias frames — provided the physics of how the parameter perturbs the image is known well enough to design the input pre-processing.

## Implementation on pymmcore-plus

On a pymmcore-plus rig, the deformable mirror (DM) is exposed as a `StateDevice` whose state vector is the Zernike coefficient vector. The embedded-NN AO loop interleaves **bias frames** (DM set to known offset Zernike modes) with **science frames** (DM set to the NN-predicted correction):

```python
from useq import MDAEvent
from src.core.hardware.core import run_events

# Pre-trained MLAO network. Contract: predict_zernike(bias_imgs, biases) -> Zernike vector in rad.
predict_zernike = load_mlao_model("mlao_2p_astigmatism_coma.pt")

DM = "DeformableMirror"         # StateDevice: states are Zernike coefficient presets
BIAS_MODES = [(3, +1.0), (3, -1.0), (4, +1.0), (4, -1.0)]  # (mode_idx, amplitude_rad)
MAIN_CHANNEL = "GFP_2P"

def embedded_ao_timelapse(core, positions, n_frames=200, dt_s=30.0, correct_every=10):
    """Multi-position timelapse with per-N-frame embedded-NN aberration correction.

    Every correct_every frames we acquire a small bias stack under the DM and
    let the NN predict the residual Zernike vector; the DM state for subsequent
    science frames is set to -prediction (the correction).
    """
    state = {
        "zernike": [0.0] * 15,                   # current correction per position
        "bias_buf": {i: [] for i in range(len(positions))},
    }

    def on_frame(img, event, meta=None):
        md = event.metadata or {}
        if md.get("phase") != "bias":
            return
        pos_idx = md["pos_idx"]
        state["bias_buf"][pos_idx].append((md["bias"], img))
        if len(state["bias_buf"][pos_idx]) == len(BIAS_MODES):
            biases, imgs = zip(*state["bias_buf"][pos_idx])
            dz = predict_zernike(imgs, biases)     # NN inference in the loop
            state["zernike"] = [-c for c in dz]    # apply as correction
            state["bias_buf"][pos_idx].clear()

    def set_dm(coeffs):
        core.setProperty(DM, "ZernikeCoefficients", ",".join(map(str, coeffs)))
        core.waitForDevice(DM)

    def gen():
        for i in range(n_frames):
            for pos_idx, (x, y) in enumerate(positions):
                t = i * dt_s
                if i % correct_every == 0:
                    # bias stack: perturb one Zernike at a time, image each
                    base = list(state["zernike"])
                    for mode_idx, amp in BIAS_MODES:
                        biased = list(base)
                        biased[mode_idx] += amp
                        set_dm(biased)
                        yield MDAEvent(
                            x_pos=x, y_pos=y,
                            channel={"config": MAIN_CHANNEL},
                            metadata={"phase": "bias", "pos_idx": pos_idx,
                                      "bias": (mode_idx, amp)},
                        )
                # science frame with current (possibly just-updated) correction
                set_dm(state["zernike"])
                yield MDAEvent(
                    x_pos=x, y_pos=y,
                    channel={"config": MAIN_CHANNEL},
                    min_start_time=t,
                    metadata={"phase": "main", "pos_idx": pos_idx, "i": i},
                )

    return run_events(core, gen(), on_frame=on_frame)
```

Production hooks in `src/core/`:

- `../../../src/core/workflows/autofocus.py` — already hosts the sweep-and-fit strategies for Z. Embedded-NN AO is the same pattern generalised to a **vector** (Zernike coefficients) instead of a scalar (Z). A future `src/core/workflows/adaptive_optics.py` would expose `make_ao_state(core, modes, bias_schedule, predictor)` / `update_ao(img_bias_stack)` mirroring `make_focus_state` / `check_and_correct_focus`. It does not exist yet — flag as a build-sprint candidate when we get a DM-equipped rig.
- `../../../src/core/hardware/core.py` — `run_events` is the dispatcher; bias frames and science frames are just extra `MDAEvent`s with a `"phase"` metadata tag that `on_frame` keys on.
- Missing piece on most rigs: the deformable mirror itself. Without a DM the correction can't be applied, but the *architecture* (sparse-parameter sweep → physics-conditioned NN → inference callback) transfers to correction-collar tuning, SIM-pattern phase calibration, and any piezo-driven alignment.

Calibration cost and transferability: the paper's key claim is that the network architecture transfers across modalities (2P, 3P, SIM) because the pseudo-PSF embedding makes the input nearly specimen-independent. In practice each modality still needs a short retraining on representative specimen data — but the design itself (which modes to bias, how to pool them, the pseudo-PSF pre-processing) is reused. On a new rig, expect a one-off offline training run of a few thousand simulated aberration-sample pairs plus a few hundred real bias stacks.
