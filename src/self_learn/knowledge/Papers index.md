# Papers — researched

Canonical citation targets for smart-microscopy and microscopy-physics literature. **Every paper here has been verified online via DOI + abstract fetch.** Never cite a paper in any other knowledge note using plain-text "Smith et al. 2022" — link to the paper's note here as `[[../../Papers/Smith 2022]]` (file slug is `Name Year`; descriptive title lives in the index table) so the reader can always reach the DOI + source.

Ordered chronologically to read as the field's trajectory: pre-DL target-driven single-cell tracking (2004) → pre-DL active-learning acquisition with explicit bleach/phototox cost (2009) → online-classifier-driven acquisition (2011) → adaptive light-sheet alignment (2016) → curiosity-driven RL formalism imported as aspirational novelty-driven acquisition recipe (Pathak 2017) → deep-learning restoration + microscope-based cybergenetic per-cell transcription control (2018) → deep-learning single-shot autofocus + programmable multimodal fluidics (2019) → Python-native programmable-acquisition substrate (Pycro-Manager, 2021) → event-driven triggering (2022) → per-object parameter adaptation (2023) → deep-MPC predictive optogenetic control of per-cell dynamics (2024) → outcome-driven optogenetic closed-loop + LLM-agent-driven instrument control (2025).
