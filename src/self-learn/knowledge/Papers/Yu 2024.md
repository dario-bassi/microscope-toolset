## Abstract

Microscopy is an indispensable tool for collecting biomedical information in pathological diagnosis, but manual annotation, measurement and interpretation are labor-intensive and costly. Here, we propose a task-driven framework powered by large models that excel in visual analysis and real-time control, paving the way for the next generation of microscopes. We achieve proof-of-concept success on clinical tasks, specifically in adaptive analysis of H&E-stained liver tissue slides. This work demonstrates the advanced capabilities for future digital pathology, setting a new standard for intelligent, efficient, and real-time analysis in clinical applications.

## Smart microscopy principle

The task-driven framework (TDF) inverts whole-slide pathology's standard "scan everything, look at it later" pipeline: a pathology-specific vision-language foundation model (PLIP — pre-trained on >200,000 pathology image-text pairs) reads each acquired tile, scores it against the current diagnostic task, and *issues control commands back to the microscope* — pick the next stage coordinate, switch the objective, change exposure, change frame rate. The slide is never fully scanned at high magnification; only the regions the model deems diagnostically informative for the current question get the photon and time budget.

The architecture runs as a closed loop: acquire → encode (PLIP) → decide (task head) → reconfigure (stage / objective / exposure) → acquire next. For the demo task — H&E liver-tumour qualitative detection plus VETC (vessels-encapsulating-tumour-clusters) prognostic grading — the system surveys at 10× to localise tumour, then autonomously switches to a 20× objective and a different exposure setting (1.0 ms vs 0.2 ms) on tumour ROIs to score VETC. Two PLIP heads are fine-tuned, one per task and magnification.

What separates this from earlier survey→zoom papers (Conrad 2011 Micropilot, Tosi 2021 AutoScanJ, Shi 2024 SmartLLSM, Kandel 2023 FAST) is the *encoder*. PLIP is a foundation model — a single pre-trained backbone that transfers across pathology tasks (cancer detection, grading, cell counting, tissue-area quantification) with task-specific fine-tuning rather than a hand-crafted phenotype classifier or YOLO detector trained per-task. This is the Morgado 2024 "task-driven microscopy" axis instantiated: the score driving acquisition is conditioned on the research question (tumour? VETC? cell count?), and a pretrained semantic encoder makes that conditioning re-targetable without a fresh detector.

The paradigm transfers beyond pathology: the same loop — foundation-model encoder + task head + microscope-control bindings — applies to any modality where (a) overview FOVs vastly outnumber regions worth high-mag follow-up and (b) a pretrained domain-specific encoder exists (cell-painting foundation models, electron-microscopy foundation models, the upcoming "microscopy CLIP" class).

## Implementation on pymmcore-plus

The TDF loop maps cleanly onto an `MDAEvent` generator with feedback. The on-frame callback runs the foundation-model encoder + task head; the generator branches on the model's decision, emitting either another survey event (low-mag, next grid point) or a zoom event (high-mag, current ROI, new exposure).

```python
from useq import MDAEvent
from src.core.hardware.core import run_events

def task_driven_pathology(core, grid_xy, encoder, task_head,
                          low_mag_obj="10x", high_mag_obj="20x",
                          channel="brightfield", task="tumor"):
    """TDF-style closed-loop pathology acquisition.

    encoder(image) -> feature vector (e.g. PLIP CLS token).
    task_head(features, task) -> {"action": "zoom"|"skip"|"continue",
                                  "exposure_ms": float}.
    """
    state = {"hits": [], "phase": "survey"}

    def on_frame(img, event, meta=None):
        feats = encoder(img)
        decision = task_head(feats, task=task)
        if decision["action"] == "zoom" and state["phase"] == "survey":
            state["hits"].append((event.x_pos, event.y_pos,
                                  decision["exposure_ms"]))

    def gen():
        # Phase 1: low-mag survey at every grid point.
        core.setProperty("Objective", "Label", low_mag_obj)
        core.waitForDevice("Objective")
        for x, y in grid_xy:
            yield MDAEvent(x_pos=x, y_pos=y, channel={"config": channel},
                           exposure=0.2)
        # Phase 2: high-mag re-visit of model-flagged hits.
        state["phase"] = "zoom"
        core.setProperty("Objective", "Label", high_mag_obj)
        core.waitForDevice("Objective")
        for x, y, exp_ms in state["hits"]:
            yield MDAEvent(x_pos=x, y_pos=y, channel={"config": channel},
                           exposure=exp_ms)

    return run_events(core, gen(), on_frame=on_frame)
```

Production hooks in `src/core/`:

- `../../../src/core/workflows/multiscale.py` — `select_rois` + `multiscale_acquire` already implement the survey→rank→zoom hierarchy with a pluggable score; TDF's contribution is the *score function* (PLIP-encoded tile, task-conditioned head). On a real instrument the encoder is a CLIP-style image-text model and the task head is a small MLP fine-tuned per question.
- `../../../src/core/workflows/scanning.py` — `grid_positions` + `scan_and_detect` provide the survey primitive; replace the geometric/intensity-based "is this tile interesting?" with the foundation-model score.
- A `foundation_model_score` module does not yet exist. A clean home would be `src/core/workflows/fm_score.py` exposing (a) `make_encoder(name)` returning a PIL/numpy → embedding callable, (b) `task_head(features, task, classes)` returning a decision dict, (c) per-task exposure / objective hints.

Calibration on a real prep (taking the paper's clinical-pathology focus seriously):

- **Fine-tune per task on per-magnification data.** Yu et al. fine-tuned *two* PLIP heads — one for 10× tumour detection, one for 20× VETC grading. A single encoder serving both magnifications without head swap silently degrades; magnification-specific heads are not optional.
- **Validate the score against a fully-scanned reference slide before unattended runs.** Compute precision/recall of the model's "zoom here" calls vs ground truth tumour mask; tune the decision threshold so recall meets clinical needs before the threshold is used to *skip* tiles.
- **Audit log of skipped tiles.** Unlike a full WSI scan, TDF leaves no record at high mag of regions it deemed uninteresting. For diagnostic use, persist the model's per-tile score and decision; a pathologist must be able to override a missed call.
- **Encoder generalisation across staining batches and scanners.** Foundation models trained on one clinical site's H&E variation can drift on another. The TDF paradigm requires either a per-site fine-tune or stain-normalisation in front of the encoder.
